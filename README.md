# ICRI-STE Statutes Website

A static, responsive GitHub Pages website for the ICRI-STE statutes and governance framework.

## Package structure
- `index.html` — website homepage and statutes content
- `assets/styles.css` — responsive styling and print stylesheet
- `assets/site.js` — navigation and provision search
- `assets/*.svg` — logo and original vector figures

## Publish with GitHub Pages
1. Create or open the repository for the statutes website.
2. Upload the contents of this package (not the enclosing ZIP directory) to the repository root.
3. Ensure `index.html` is in the repository root.
4. In **Settings → Pages**, choose the deployment source (usually `Deploy from a branch`), select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish and open the URL shown in the Pages settings.

## Important governance note
This is a proposed web publication edition, organised into 15 Parts and 62 consolidated provisions. It is not a verbatim reproduction of the longer 133-article draft. Before formal adoption, reconcile it against the approved master statutes, confirm the legal form and jurisdiction of ICRI-STE, confirm authorised office-holders, and obtain appropriate legal review. The three LLCs are described as associated by research alignment only; no ownership, subsidiary relationship or liability is presumed.

## Customisation
Edit the text in `index.html`. Replace or update the SVG files in `assets/` if official approved brand artwork becomes available. Keep asset paths relative so the site works on GitHub Pages project sites.
